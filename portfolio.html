Cloak: AI-Driven Network Threat Detection

Cloak is a plug-in network monitoring device. An Orange Pi connected to a network captures live traffic, organizes it into events, and uses machine learning to flag activity that may be malicious. Findings appear on a dashboard where users can review alerts and investigate them with the help of a small language model.

Network SecurityMachine Learning XGBoostIsolation Forest Half-Space TreesMITRE ATT&CK Orange Pi

How it works

  • Capture: the Orange Pi reads network traffic and groups it into events
  • Anomaly detection: Isolation Forest and Half-Space Trees learn a baseline for each network and flag traffic that deviates from it, catching threats nobody has seen before
  • Known-threat classification: XGBoost identifies known malicious patterns, such as behavior mapped to MITRE ATT&CK techniques or traffic to known-bad IPs
  • Investigation: a dashboard surfaces flags and alerts, with an SLM assistant to answer questions and help analysts investigate

My role

Flex team member focused on the AI team, working on the machine learning models behind detection and classification.
